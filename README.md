# MOXIEMO 2.0

AI-powered marketing platform for small business owners.

## Stack

- **Frontend**: React + Vite + TypeScript + Tailwind CSS + shadcn/ui
- **Backend**: Supabase (Postgres, Auth, Edge Functions, RLS)
- **AI**: Claude API (Anthropic)
- **Payments**: Stripe
- **Email**: Resend
- **Deployment**: Vercel

## Local Development

```bash
npm install
npm run dev
```

## Deploy

```bash
npx vercel deploy --prod
```
